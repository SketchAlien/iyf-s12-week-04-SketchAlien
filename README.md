## Project Description

A collection of JavaScript exercises covering variables, data types, functions, control flow, arrays, objects, and JSON. Includes two mini-projects: a Calculator and a Student Grade Tracker.

## Technologies Used

- HTML5

- JavaScript (ES6+)

## Features

- Interactive Calculator with division-by-zero handling

- Student Grade Tracker using arrays and objects

- Daily challenges (FizzBuzz, Reverse String, etc.)

## How to Run

1. Clone this repository

2. Open `index.html` in your browser

OR

Use Live Server in VS Code. Check the browser console (F12) to view the output.

## Lessons Learned

I learned how to use array methods like `map`, `filter`, and `reduce` to manipulate data, and how to use objects to store complex data.

## Challenges Faced

I struggled with variable scope (accidentally declaring the same variable twice), but I learned how to debug syntax errors using the browser console.
